# PiuLink Windows 0.2.145

Windows x64 整合版包含 Host 0.2.145 和 Client 0.2.41。首次安装可下载 92.65 MB 的离线小包。它在本机还原出与应用内更新相同的标准整合包。已有 Windows 用户可通过应用内检查更新升级，旧版独立 Host 和 Client 的更新入口也指向整合版。

- 远程唤醒的状态、提示和本机引擎控制随所选显示语言切换。“跟随系统”读取当前 Windows 用户的显示语言。
- 如果上次会话已释放且主机空闲，重新连接可以继续恢复显示布局，减少因旧会话状态引起的反复等待。
- Windows 主机继续将 DXGI 采集和 NVENC 资源管理迁到 Rust。本版精简了引擎中的编解码依赖，保留 NVENC AV1 硬编码。离线小包比 0.2.144 少 2,516,070 字节。

在已安装 0.2.142 的 Windows 主机上完成整合版卸载重装，安装前后的 14 条配对和 54 项配置与状态指纹一致。M367FC 平板使用原有主机卡片连续两次连接，实际显示了测试窗口的三次颜色变化。两次均取得持续呈现的帧，断开后主机恢复空闲。
