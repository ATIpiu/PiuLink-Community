# PiuLink Rust · 全新主线公开预览

PiuLink Rust 是完全全新的开发版本。自本次发布起，后续优化、修复和功能迭代统一基于新的 main。旧版 fork、旧版 commit 和基于旧主线的 PR 均不接受合并。希望继续贡献的开发者，请从新的 main 创建新的 fork 或分支，重新实现所需改动并提交新的 PR。

项目继续使用原来的 GitHub 仓库和官网。旧主线归档在 [历史分支](https://github.com/ATIpiu/PiuLink-Community/tree/history/pre-rust-main-20261127)，旧版本的标签和安装包可按原链接查阅。上述规则适用于项目维护者接收贡献的流程，各组件继续遵循仓库中的许可和上游署名。

## Rust 代码在哪里

[串流引擎源码](https://github.com/ATIpiu/PiuLink-Community/tree/rust-2026.11.28/engines/rust)含码率控制、Windows Host 适配、实时编解码调用、媒体封包、RTSP、音视频 FEC、跨块整帧重组及相关测试。平台原生接口继续承担硬件编解码、显示与部分会话工作。本版是 Rust 主线的起点，尚未完成全部代码的等价移植。详见[源码目录及构建入口](https://github.com/ATIpiu/PiuLink-Community/blob/rust-2026.11.28/engines/rust/README.md)。

安装文件的 SHA-256 列在本页附件 [SHA256SUMS.txt](https://github.com/ATIpiu/PiuLink-Community/releases/download/rust-2026.11.28/SHA256SUMS.txt)。Windows 安装包为公开预览，鸿蒙 HAP 仅供模拟器验证。

从源码构建桌面控制端时，请使用[已通过 Windows 与 Linux 构建验证的源码](https://github.com/ATIpiu/PiuLink-Community/tree/7eaa2c06d0f532a5a6b59f0d05007dda0dc33177)。使用发布标签检出的 Linux 工程可应用[诊断组件引用修正](https://github.com/ATIpiu/PiuLink-Community/commit/7eaa2c06d0f532a5a6b59f0d05007dda0dc33177.patch)。此修正仅影响源码构建，安装附件的校验值见 SHA256SUMS.txt。
