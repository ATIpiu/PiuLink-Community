# 一台 Host，一条直连邀请

在 Windows Host 首页的连接信息区点「开启直连邀请」，等按钮变成「复制直连邀请链接」后复制。客户端在「添加电脑」中粘贴整条链接。Windows、Android、Mac、Linux 客户端都沿用原有的配对和串流流程。iPhone 源码的 Add Host 入口使用同一协议。

开启期间可以反复复制同一条链接，也可以给多台设备使用。Host 地址变化后会重新登记。已配对的客户端可优先使用仍然可达的已知地址。关闭邀请会停止地址更新，旧链接最多再提供 90 秒查询。再次开启会生成新链接。要收回已配对设备的连接权限，请在 Host 的配对设备管理中移除该设备。

## 哪些网络可以连接

第一阶段使用现有直连路径。客户端尝试 Host 登记的本机地址和 VPS 观察到的出口 IP，核对 Sunshine 的 UUID，再进入原有证书配对流程。适用于同一局域网、相互可达的虚拟组网，以及防火墙和串流端口已就绪的公网 IPv4 或 IPv6。地址探测成功只说明控制端口可达，音视频仍需要各自的传输端口。

两端只有互不连通的内网地址时，界面会提示当前网络无法直连。此阶段使用 Sunshine 默认 HTTP 端口 47989，保留手动输入自定义端口的入口。VPS 提供地址登记和查询，视频、音频、输入和文件沿选定的设备间路径传输。

## 协议 v1

| 操作 | 契约 |
| --- | --- |
| 复制邀请 | `https://atipiu.org:8443/piulink/join#<room>.<hostUuid>`。浏览器访问只显示粘贴说明。 |
| 登记 | `POST /piulink/v1/publish`。Bearer 为本机生成的 32 字节随机数的小写十六进制文本。JSON 仅含小写 UUID 字段 `hostId` 和至多 12 个 IP 字面量的 `addresses`。成功返回 204。 |
| 查询 | `POST /piulink/v1/resolve`。Bearer 为邀请中的 `room`，请求体为空。成功返回 Host 标识和候选地址，离线或过期返回 404。 |
| 续期 | Host 每 30 秒登记一次。VPS 保存最多 90 秒的内存记录。 |

`room` 为 `SHA256(ASCII(ownerHex + "\n" + lowercaseHostUuid))` 的小写十六进制表示。VPS 使用登记凭据计算可更新的房间；拿到邀请的客户端可以查询这台 Host，无法用查询凭据覆盖该房间。Host 使用 Windows 凭据管理器或 Linux 用户私有文件保存登记凭据。UUID 用来排除地址相同的其他主机，设备授权继续由原有配对机制负责。


## 跨网直连

邀请服务支持端点发现与 ICE 协商。两端尝试 IPv4、IPv6 候选；可达时，媒体直接在设备之间传输。NAT、防火墙和运营商策略会影响结果。文件传输使用单独的配对通道。
