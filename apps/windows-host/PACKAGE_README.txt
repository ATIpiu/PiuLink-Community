PiuLink Host v0.1.0 alpha 1
ATIPiu Labs · Ryan

This is an unsigned internal alpha build for Windows x64. Windows SmartScreen may warn because a commercial code-signing certificate has not been configured.

PiuLink Host checks Windows, GPU, Tailscale, Sunshine, the local Sunshine endpoint and Sunshine firewall rules. This internal build can install its pinned, signed Sunshine 2026.516.143833 MSI after explicit GPL acknowledgment and a Windows UAC prompt. It does not automatically change firewall or driver settings.

Install Tailscale through PiuLink's official-download guide. Sunshine remains a separate GPLv3 program even when conveyed with PiuLink. PiuLink Host is not affiliated with or endorsed by either upstream project.
